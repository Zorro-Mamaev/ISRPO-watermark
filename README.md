# BMP Watermark

## Описание проекта

**BMP Watermark** — учебный командный проект на C++20 для наложения цифрового водяного знака на изображения формата BMP.

Программа будет принимать два BMP-файла: исходное изображение и водяной знак, обрабатывать их и сохранять результат в новый BMP-файл.

**Статус проекта:** в разработке.

## Цели проекта

* Изучить устройство BMP-файлов.
* Реализовать чтение и запись BMP на C++20.
* Разработать алгоритм наложения водяного знака.
* Освоить командную разработку с использованием Git и GitHub.
* Настроить автоматическую сборку и тестирование через GitHub Actions.

## Планируемая архитектура

Программа будет состоять из трёх основных компонентов.

### 1. BMP Image

Класс `ImageBMP` будет отвечать за загрузку, хранение и сохранение BMP-изображений.

### 2. Watermark

Функция наложения будет смешивать цветовые компоненты изображений по формуле:

`result = original * (1 - alpha) + watermark * alpha`

Где `alpha` — коэффициент прозрачности водяного знака.

### 3. Main

Основная программа будет получать пути к файлам, загружать изображения, выполнять наложение и сохранять результат.
